# Documentation Index

This folder groups project documentation by purpose and lifecycle stage. Use the links below to navigate the main documentation areas.

## Quick usage

- Start in [requirements](./requirements/) for business and technical requirements.
- Check [kb](./kb/) for reusable implementation decisions and technical knowledge.
